安全審查清單 (Security Review Checklist)

概述

本清單用於審查 Bricks4Agent 各語言實作的安全性，確保所有模組符合安全最佳實踐。

1. 認證與授權 (Authentication & Authorization)

1.1 密碼處理

  • [ ] 使用安全的雜湊演算法 (PBKDF2/bcrypt/Argon2)

  • [ ] 足夠的迭代次數 (≥100,000 for PBKDF2)

  • [ ] 使用隨機鹽值 (≥16 bytes)

  • [ ] 密碼比對使用常數時間函數

  • [ ] 禁止明文儲存密碼

  • [ ] 密碼強度驗證

1.2 MFA 實作

  • [ ] TOTP 符合 RFC 6238

  • [ ] 使用安全的隨機數生成器產生密鑰

  • [ ] 密鑰儲存已加密

  • [ ] 復原碼使用一次性設計

  • [ ] 復原碼已雜湊儲存

  • [ ] 限制 MFA 嘗試次數

1.3 Session 管理

  • [ ] Session ID 使用安全隨機數

  • [ ] Session 有適當的過期時間

  • [ ] 支援 Session 撤銷

  • [ ] 登出時正確銷毀 Session

  • [ ] 敏感操作需重新驗證

1.4 JWT 實作

  • [ ] 使用強簽章演算法(現行實作一律為 HS256 對稱簽章,例如 packages/csharp/broker-core/Services/ScopedTokenService.cs:83、packages/csharp/security/JWT/JwtHelper.cs:82;審查時確認 HMAC 金鑰 ≥256 bit 且不入 repo、驗證端鎖定演算法;需第三方驗簽時再評估 RS256/ES256)

  • [ ] 適當的 Token 有效期

  • [ ] 包含必要的 Claims

  • [ ] 驗證所有 Claims

  • [ ] Refresh Token 安全儲存

2. 輸入驗證 (Input Validation)

2.1 一般輸入

  • [ ] 驗證所有用戶輸入

  • [ ] 使用白名單驗證

  • [ ] 驗證資料類型和範圍

  • [ ] 限制輸入長度

  • [ ] 處理特殊字元

2.2 SQL Injection 防護

  • [ ] 使用參數化查詢

  • [ ] 禁止字串拼接 SQL

  • [ ] ORM 正確使用

  • [ ] 動態查詢有額外驗證

2.3 XSS 防護

  • [ ] 輸出編碼 (HTML/JS/URL)

  • [ ] Content-Type 正確設定

  • [ ] CSP Header 設定

  • [ ] 避免使用 innerHTML

2.4 正則表達式

  • [ ] 設定超時限制 (ReDoS 防護)

  • [ ] 避免複雜的巢狀量詞

  • [ ] 輸入長度限制

3. 加密 (Cryptography)

3.1 加密演算法

  • [ ] 使用現代加密標準 (AES-256, RSA-2048+)

  • [ ] 禁止使用過時演算法 (MD5, SHA1, DES)

  • [ ] 使用安全的操作模式 (GCM, CTR)

  • [ ] IV/Nonce 不重複使用

3.2 金鑰管理

  • [ ] 金鑰安全儲存

  • [ ] 金鑰不寫入日誌

  • [ ] 支援金鑰輪換

  • [ ] 環境變數/密鑰管理服務

3.3 隨機數生成

  • [ ] 使用密碼學安全的 PRNG

  • [ ] 禁止使用 Math.random() 等

  • [ ] 足夠的隨機性

4. 錯誤處理 (Error Handling)

4.1 錯誤訊息

10. 各語言特定檢查

10.1 C# / .NET

  • [ ] SQL 一律經 BaseOrm 參數化，不拼接字串

  • [ ] 密碼雜湊使用靜態 Rfc2898DeriveBytes.Pbkdf2 API，且不改既有迭代次數 / 鹽 / 雜湊長度與儲存格式

  • [ ] 秘密值 / token / 雜湊比對使用 CryptographicOperations.FixedTimeEquals

  • [ ] 無 BinaryFormatter 等不安全反序列化

  • [ ] 外部程序以 UseShellExecute = false + ArgumentList 啟動，不經 shell

  • [ ] npm run test:dotnet10(警告視為錯誤)通過

10.2 Node.js/TypeScript

  • [ ] 無 eval 使用

  • [ ] 無 Function() 建構

  • [ ] 原型污染防護

  • [ ] 嚴格模式啟用

10.3 前端 JavaScript

  • [ ] 無 innerHTML 直接賦值

  • [ ] 動態 HTML 一律經 escapeHtml();需輸出原始 HTML 時明確用 raw() 標記(isRawHtml() 只認 raw() 打上的 Symbol 品牌，手寫 / JSON.parse 的 { __html } 不算授權)—— 見 packages/javascript/browser/ui_components/utils/security.js

  • [ ] node tools/scripts/audit-csp.mjs 硬零通過(無 <style> 注入、innerHTML 模板內無 style= / on*=、無 eval / new Function / javascript: URL)

  • [ ] 無 SVG(<svg、createElementNS、data:image/svg),圖形一律 Canvas —— 同由 audit-csp.mjs 強制

  • [ ] 無 document.write

  • [ ] localStorage 敏感資料加密

  • [ ] postMessage 來源驗證
